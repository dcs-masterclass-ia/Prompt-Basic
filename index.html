Le syndrome de l'Amnésie

Quand vous collez un texte très long (ex: 10 pages), l'IA retient bien le début et la fin, mais oublie très souvent le milieu.

Lu & Retenu
Oublié / Ignoré
Lu & Retenu

Comment l'IA lit votre prompt :

1. "Tu es recruteur expert..." (Retenu)

2. [Texte de 5 pages de CV]

3. "Exclus les profils juniors." (Oublié)

4. [Texte de 5 pages de CV suite]

5. "Fais un tableau." (Retenu)

La Solution

Placez toujours vos instructions d'action ("Fais un tableau", "Exclus ceci") TOUT À LA FIN de votre prompt, après le long texte collé.

Comprendre les fondations

C'est quoi un Token ?

L'IA ne lit pas des mots. Elle lit des fragments de mots appelés tokens. Comprendre ça change tout.

Architecture du prompt

System Prompt vs User Prompt

System Prompt

Le cerveau permanent

  • → Définit la personnalité et le rôle global de l'IA
  • → Invisible pour l'utilisateur final
  • → Persiste sur toute la conversation
  • → Idéal pour les règles métier, le ton, les contraintes
"Tu es un conseiller RH senior. Tu t'exprimes toujours de façon empathique. Tu ne donnes jamais de conseil juridique."

User Prompt

La demande du moment

  • → La question ou tâche spécifique
  • → Varie à chaque échange
  • → Peut surcharger le system prompt si trop précis
  • → C'est ici qu'on applique ROCEF
"Rédige une réponse à cet email d'un collaborateur qui demande une augmentation de 15%."

Règle d'or : Mettez les règles permanentes dans le System Prompt. Mettez la tâche du moment dans le User Prompt. Ne mélangez pas les deux.

Paramètre clé

La Température expliquée

Elle ne contrôle pas l'intelligence — elle contrôle l'aléatoire. C'est le curseur entre précision et créativité.

0.0
1.0

0.0 – 0.3

Déterministe

Résultats stables et répétables. Idéal pour : code, analyse, extraction de données, classification.

0.5 – 0.7

Équilibré

Recommandé pour la plupart des usages pros : emails, rédaction, résumés, communication.

0.8 – 1.0

Créatif

Résultats variés et surprenants. Idéal pour : brainstorming, fiction, slogans, idéation.

Piège fréquent : Mettre la température à 1.0 pour "maximiser l'intelligence". C'est faux — vous augmentez juste le chaos. Pour du code ou des faits, restez sous 0.3.

Vrai ou Faux ?

Testez votre compréhension

"Pour rédiger un rapport financier précis avec des chiffres exacts, il vaut mieux utiliser une température de 0.9 pour que l'IA soit plus intelligente."

Erreur classique

Le Prompting Négatif

Les LLM traitent très mal les négations. Dire "ne fais pas X" est souvent interprété comme "fais X".

❌ Ce qu'on écrit souvent

"Ne sois pas trop formel."

→ L'IA ne sait pas où s'arrêter. Résultat imprévisible.

"N'utilise pas d'emojis."

→ Fonctionne parfois, échoue souvent sur des tâches longues.

"Ne dépasse surtout pas 100 mots."

→ La contrainte négative est ignorée régulièrement.

✅ Ce qu'on devrait écrire

"Adopte un ton décontracté et direct."

→ L'IA sait exactement où aller.

"Texte pur, sans aucun symbole ni emoji."

→ Contrainte positive, appliquée systématiquement.

"Réponds en exactement 80 mots."

→ Contrainte affirmative, résultat contrôlé.

Règle universelle : Dites toujours à l'IA CE QU'ELLE DOIT FAIRE, jamais ce qu'elle ne doit pas faire.

Technique avancée

Le Few-Shot Prompting

Montrer des exemples du résultat attendu est souvent 10x plus efficace qu'une longue description.

Zero-shot

Aucun exemple. L'IA interprète librement. Résultats variables.

"Résume cet article."

One-shot

Un exemple. L'IA comprend le format et le ton attendus.

Few-shot ⭐

2 à 5 exemples. Résultats cohérents et reproductibles.

Exemple Few-Shot — Classification d'emails

Classe cet email dans une catégorie. Voici des exemples :

Email: "Votre colis est en route."

Catégorie: LOGISTIQUE

Email: "Votre facture du mois de novembre."

Catégorie: FACTURATION

Email: "Nous avons bien reçu votre réclamation."

Catégorie: SAV

→ Maintenant classe : "Votre abonnement expire dans 7 jours."

Le Pouvoir des Personas

Assigner un rôle précis à l'IA est la technique qui a le plus d'impact à effort égal. Le rôle conditionne tout.

"Tu es un avocat spécialisé en droit du travail"

→ Langage précis, nuancé, mentions de risques légaux

"Tu es un CFO avec 20 ans d'expérience en M&A"

→ Analyse financière, ratios, vision stratégique

"Tu es un copywriter expert en B2B SaaS"

→ Accroche, bénéfices clients, appel à l'action

Maîtrise du format

Les Contraintes qui changent tout

Un bon prompt n'est pas seulement ROCEF. C'est aussi des contraintes précises qui rendent le résultat directement exploitable.

Contraintes de longueur

→ "En exactement 3 phrases"
→ "Résumé exécutif de 50 mots max"
→ "5 bullet points, une idée par point"
→ "Un email de 4 paragraphes, pas plus"

Contraintes de style

→ "Niveau de lecture : lycéen"
→ "Voix active uniquement"
→ "Chaque affirmation doit être chiffrée"
→ "Langue : français, vouvoiement"

Contraintes de structure

→ "Réponds en tableau Markdown"
→ "Format : Problème / Solution / Bénéfice"
→ "Numérote chaque étape"

Contraintes de contenu

→ "Inclure au moins 2 exemples concrets"
→ "Citer une source ou un chiffre réel"
→ "Terminer par un appel à l'action"
Technique avancée

Le Meta-Prompting

Demander à l'IA de créer ou d'améliorer son propre prompt. L'IA connaît ses faiblesses — utilisez-les.

Amélioration

"Voici mon prompt : [PROMPT]. Comment l'améliorer pour obtenir un résultat plus précis ?"

Génération

"Génère le meilleur prompt possible pour qu'une IA rédige une fiche de poste pour un Data Engineer senior."

Variantes

"Donne-moi 3 versions différentes de ce prompt, du plus formel au plus créatif."

Astuce pro : Après tout résultat décevant, demandez : "Quel prompt aurais-tu préféré recevoir pour mieux répondre ?"

Risque critique

Les Hallucinations

L'IA invente avec confiance. Statistiques, noms, dates, citations — tout peut être fabriqué de toutes pièces.

Données à toujours vérifier

  • Chiffres, statistiques, pourcentages
  • Citations et auteurs
  • Noms de personnes réelles
  • Dates et événements récents
  • Liens et URLs (souvent inventés)
  • Contenu juridique ou médical

Comment réduire les hallucinations

Demandez "Si tu n'es pas sûr, dis-le explicitement"

Fournissez les données source dans le prompt

Utilisez des modèles avec recherche web activée pour les faits récents

Ajoutez : "Cites tes sources ou indique ton niveau de certitude"

Sécurité & confidentialité

Ce qu'on ne met jamais dans un prompt

Vos données envoyées à une IA peuvent transiter, être stockées, utilisées pour l'entraînement. Protégez-vous.

Données financières

Numéros de compte, RIB, données de paie, comptes de résultat internes non publics

Données personnelles

Numéros de sécu, adresses privées, données de santé, mots de passe — RGPD oblige

Secrets industriels

Formules, brevets non déposés, stratégies commerciales confidentielles, codes source propriétaires

ChatGPT (gratuit)

Données utilisées pour entraînement

Désactivable dans les paramètres

Claude (Anthropic)

Politique claire de non-rétention

Vérifiez les CGU de votre plan

Exercice final

Le prompt d'expert — complétez

Un prompt expert commence par assigner un précis. Il utilise un ou plusieurs pour guider le format attendu. Il formule toutes les règles de manière , jamais négative. Il précise la selon la nature de la tâche. Et il termine toujours par une contrainte de précise.
